# nyc-taxi-insights
Analysis of the public NYC TLC Yellow Taxi trip records (2024, ~40M rows, Parquet, no login required) with DuckDB SQL and pandas.

**Goal:** answer business questions a data analyst gets asked, and present them clearly: demand by hour/zone, tipping behaviour by payment type, airport trip economics, congestion and speed trends, fare anomalies.

**Scope (v1):** reproducible download + data-quality checks · SQL query library (CTEs, window functions) · pandas/Plotly notebooks · static interactive dashboard on GitHub Pages · INSIGHTS.md with 6-8 findings, each with the query, chart and recommendation.

Status: scaffolding. Roadmap in issues.
